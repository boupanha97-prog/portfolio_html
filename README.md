# 🌐 Bou Panha - Personal Portfolio

A clean, semantic HTML personal portfolio webpage showcasing my journey, background, education, technical skills, and interests as an aspiring Full-Stack Web Developer.

---

## 📖 About The Project

This project is a personal portfolio webpage built using pure **Semantic HTML5**. It represents the foundational step of my full-stack web development journey, focusing on clean document structure, accessibility, and organized content hierarchy without reliance on external frameworks or CSS styling.

### 🌟 Key Sections

- **About Me**: An introduction to my background transitioning from business into technology and passion for building solutions.
- **Education**: Educational timeline including my Bachelor's degree and Full-Stack Development Bootcamp at TFDevs (2026).
- **Skills & Tools**:
  - **Programming Languages**: HTML5, CSS (in progress), JavaScript (in progress)
  - **Developer Tools**: VS Code, Git, Chrome DevTools
  - **Soft Skills**: Problem Solving, Communication, Team Collaboration
- **Interests**: Personal passions including technology innovation, open-source contribution, photography, and travel.
- **Contact Information**: Direct contact link for collaborations and opportunities.

## 🚀 Getting Started

To view and run this project locally on your machine:

### Prerequisites

You only need a modern web browser (e.g., Google Chrome, Mozilla Firefox, Microsoft Edge, or Safari).

### Installation & Quick Start

1. **Clone the repository**:
   ```bash
   git clone https://github.com/boupanha97-prog/portfolio_html.git
   ```

2. **Navigate into the project directory**:
   ```bash
   cd portfolio_html
   ```

3. **Open the project**:
   - Double-click `index.html` to open it directly in your browser.
   - *Or* open the folder in [VS Code](https://code.visualstudio.com/) and use the **Live Server** extension to view it with live reloading.
